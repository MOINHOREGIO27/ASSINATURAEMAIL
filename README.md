# Gerador de Assinaturas — Moinho Régio

Gerador de assinaturas de e-mail seguindo o layout aprovado da Moinho Régio.

## Publicação no GitHub Pages

1. Envie todos os arquivos deste diretório para um repositório GitHub.
2. Em **Settings → Pages**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

O arquivo `index.html` é a página principal.
